One joke about Monday mornings, in a single line of at most 200 characters,
entered in the [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc)
competition on make.fun.

> Monday morning doesn't knock. It just walks in, eats your weekend, and asks what's for breakfast.

Monday personified as the rudest houseguest: it doesn't knock, it walks in,
devours your weekend, and then has the nerve to ask what's for breakfast.
No alarm clock, no coffee — just a three-beat escalation with the punchline
landing on the last clause.

## Run it

```sh
python3 main.py
```

This writes the joke to `/output/entry.txt` (validated: 1–200 UTF-8
characters, not only whitespace), verifying the written bytes by reading
them back.
